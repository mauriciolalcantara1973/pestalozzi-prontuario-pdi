# Prontuário Eletrônico Interdisciplinar - Associação Pestalozzi de Maceió

MVP desenvolvido como projeto de extensão universitária voltado ao registro ágil de evolução clínica e acompanhamento do Plano de Desenvolvimento Individual (PDI).

## 🎯 Escopo do MVP
- **Tela 1:** Busca ágil de assistidos por nome ou matrícula.
- **Tela 2:** Registro de evolução clínica pós-atendimento com metas do PDI.
- **Tela 3:** Linha do tempo interdisciplinar e emissão de relatório consolidado.

## 🛠️ Stack Tecnológica
- **Backend:** Python / Django
- **Frontend:** Bootstrap 5 (Foco Mobile e Acessibilidade WCAG 2.1 AA)
- **Banco de Dados:** SQLite / PostgreSQL
- **Alinhamento:** ODS 10 (Redução das Desigualdades - Meta 10.2)
